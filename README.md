# AgriSmart AI - Backend API

AI-Powered Smart Farming Assistant Backend created for Hackathon execution.

## Features
- **AI Crop Disease Detection:** Analyzes uploaded leaf images and suggests remediation actions.
- **AI Farming Assistant:** Grounded, context-aware Q&A bot utilizing farm state metrics.
- **Crop Recommendation:** Transparent rule-based score calculation matching conditions to ideal profiles.
- **Weather Intelligence:** Live OpenWeather integration with automatic fallback to realistic demo data.
- **Soil Health Analysis:** Calculates soil suitability score based on N-P-K & pH input parameters.
- **Smart Irrigation Recommendation:** Real-time water amount and schedule optimization.
- **Farm Analytics Dashboard:** Consolidated API powering frontend charts.
